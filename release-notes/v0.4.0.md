# Northstar Agent Stack v0.4.0

**Date:** 2026-10-12 · **Status:** local demo, dry-run only (`PUBLISH_DRY_RUN=true`)

## New
- **Client 0 template** (`clients/client0/`): run the owner's own X / LinkedIn / Facebook through a Slack channel exactly like
  client 1, with chat, ✅ / ✏️ / ❌ previews, `limits`, watchlist and notes. The pilot is dry run: an approved post is logged
  as `publish_result dry_run` and nothing reaches Buffer or the platforms. Guardrails use placeholders only: Viral plan,
  week-1 caps (X 4 posts + 8 replies/day, LinkedIn 4 posts/week + 2 comments/day, Facebook 1 post + 3 comments/day),
  everything approval-gated, no automated likes, follows or DMs, a plain-text check (`<<<` / `>>>` blocked), and stop and
  notify on any platform warning.
- **App:** the Clients collector reads the client0 helper (`CLIENT0_STATE_URL`, default 127.0.0.1:8772), its audit log and
  the n8n "Client0 bot" executions. Dry-run approvals show separately and never count as posts. A client's own helper
  AI meter takes precedence over the shared spend log.

## Tests
vitest 61/61, typecheck clean. Headless E2E wasn't re-run for this release because the box was overloaded; the pages are
unchanged from v0.3.0 (19/19).

## Upgrade notes
No schema change. Set `CLIENT0_STATE_URL` and `CLIENT0_AUDIT_LOG_PATH` if your paths differ from the defaults in
`app/config/clients.yaml`.
