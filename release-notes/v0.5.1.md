# Northstar agent stack v0.5.1 — 2026-10-12

**Repo now contains only the Northstar system; client instances live outside the repo.** Each client becomes its own agent instance on the server, built from the templates here.

## Changed
- `workflows/client-bot/*.json`: the 14 client-bot n8n workflows as generic templates ("Example Client", placeholder channel/ids, inactive, no credentials).
- `state-helper/`: the stdlib state helper (memory, guardrails, approvals, batches, coach), one process per instance (`CLIENT_KEY`, `CS_PORT`).
- `templates/guardrails.example.yaml` (trial/starter/growth/viral tier caps, warm-up) and `templates/notes.example.md`.
- `docs/new-client.md`: how to spin up a client instance from the templates.
- `bin/client-chrome.sh` (was a client-named script), `bin/state-helper-up.sh`: parameterised per instance.
- Self-heal: instances are configured with `SELFHEAL_INSTANCES` (none by default).

## Removed
Client instance folders, the owner template, client-named workflow exports and the client-named helper directory.

## Upgrade
Move any live instance data to `~/agency/clients/<key>/` (it was never in the repo), then follow `docs/new-client.md`. No schema change; the app is unchanged except its example `clients.yaml` and test fixtures.

Note: tags up to v0.5.0 still contain the earlier client files in history.
