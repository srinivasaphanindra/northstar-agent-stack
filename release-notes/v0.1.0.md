# Northstar v0.1.0: first tagged build (phase 1)

**Date:** 2026-10-12 · **Status:** local demo, dry-run only

> This release describes the Northstar app as it was at its own `v0.1.0` tag, before the code moved into this stack
> repository. The stack repo starts at v0.2.0, so it has no v0.1.0 commit. To run code, use v0.2.0.

## Highlights
- Mobile-first installable PWA (Next.js 15 + Tailwind 4) with an offline page and an install button.
- Email + password auth, invites with owner/admin/member roles, multi-tenant workspaces, append-only audit log.
- Onboarding wizard: business → plan pick with manual payment (an admin marks it paid) → 10-question interview as chat → connect tools → chat channel (web + Slack; Telegram behind a flag).
- Chat with the agent through a worker job queue (OpenRouter, platform or bring-your-own key, encrypted).
- Approvals inbox: drafts only go to Buffer after approval, and never in dry-run. "Open in app" handoff on phones.
- Settings for AI key, integrations (Buffer, Hootsuite, GoHighLevel, webhook, Slack), guardrails, team, channels and billing.
- Admin page with a platform-wide daily AI hard stop. Per-workspace spend caps (80/100/150 %).
- Deploy kit (VPS + systemd + Caddy + Postgres guide, Dockerfile + compose; untested).

## Tests
26 vitest tests and headless E2E 12/12.

## Known gaps
Slack only mocked, Buffer personal API key only, regex-only content check, no web push/email sending, Postgres not
exercised, no API rate limits / CSP / DPDP export. Most of these are addressed in v0.2.0 or on the [roadmap](../docs/roadmap.md).
