# Northstar Agent Stack v0.3.0

**Date:** 2026-10-12 · **Status:** local demo, dry-run only (`PUBLISH_DRY_RUN=true`)

## New in the app
- **Admin Clients dashboard** (`/admin/clients`): admin-only and mobile-first. Each client shows its profile links and today's posts, replies and comments against its caps.
- **Per-client analytics** (`/admin/clients/<key>`, 7 or 30 days): posts, replies and comments per day per platform; approvals approved/rejected; inbound messages handled; impressions where available; follower trend; AI spend against budget ($35/month on Viral); recent activity with links.
- **Viral warm-up caps** in `app/config/clients.yaml`: 4 weeks, X from 4 posts + 8 replies a day up to 15 + 30, plus LinkedIn and Facebook ramps.
- **Read-only collector** every 15 min in the worker (or `npm run collect`). It reads local logs, the client helper's GET endpoints, the n8n executions API and, only when a key file is already configured, Buffer analytics. It never calls a platform write API or the X API. Missing sources are skipped and recorded.

## Privacy
Profile handles and URLs aren't stored in the repo. The collector reads them at run time from your own config files (paths in `config/clients.yaml`, overridable by env).

## Tests
vitest 60/60 (15 new), typecheck clean, headless E2E 19/19.

## Upgrade notes
Run `npx prisma db push` in `app/` (adds `ClientProfile`, `ClientActivity`, `ClientMetric`, `CollectorRun`). Set the source paths in `.env` (see `app/.env.example`) or edit `app/config/clients.yaml`. `CLIENTS_COLLECTOR=false` turns the collector off.
