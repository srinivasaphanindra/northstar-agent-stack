# Northstar agent stack v0.5.0 — 2026-10-12

Local only, dry run (`PUBLISH_DRY_RUN=true`). Northstar app unchanged (stays v0.4.0).

## Highlights
- **Self-heal supervisor** (`selfheal/`): every 5 minutes checks n8n (and "Offer expired" task-runner storms), both client helpers, the app and its worker, the browser agent and the Chrome CDP endpoints. Restarts via the existing scripts with exponential backoff, max 3 per service per hour. Retries failed n8n executions once, only for an explicit idempotent allowlist, never anything that publishes or replies. Re-queues malformed Buffer drafts for rebuild, blocks `<<<` drafts. Every action is audited; anything unresolved, any platform warning, captcha or sign-in page becomes a JSON alert. It never edits its own code, guardrails or caps, never signs in, and never retries past platform warnings.
- **Chrome pile-up fixed**: a slow CDP answer no longer makes the launcher delete the profile lock and start a duplicate sandboxed Chrome.
- **Dry-run posts don't use caps** in client0-state.

## Upgrade
1. Copy `selfheal/` next to `bin/` and the updated `bin/client1-chrome.sh`, `bin/services-watchdog.sh`.
2. `python3 selfheal/tests/test_selfheal.py`
3. `python3 selfheal/selfheal.py once` (first run records a baseline of existing audit rows), then let the watchdog `ensure` the loop.
