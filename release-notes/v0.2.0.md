# Northstar Agent Stack v0.2.0

**Date:** 2026-10-12 · **Status:** local demo, dry-run only (`PUBLISH_DRY_RUN=true`)

This is the first release of this repository. It contains the Northstar app at v0.2.0, plus the client 1 pilot stack
(n8n workflows, `client1-state`, `browser-agent`, guardrails and service scripts). Start with [SETUP.md](../SETUP.md).

## New in the app
- **Connect with Buffer** (OAuth 2.0 + PKCE): encrypted tokens and a rotating refresh token. It's off until `BUFFER_CLIENT_ID` is set, and the personal API key still works.
- **Buffer channel picker:** one channel per platform. Publishing refuses a disconnected or locked pick.
- **Approve as queue / now / scheduled** (IST, 5 min to 180 days ahead).
- **Approve-time content check:** "numbers must be in notes" plus an AI classifier. Blocked drafts stay pending with the reason.
- **Slack harness:** fake Slack API tests, plus `npm run slack:live-check` for a throwaway workspace.

## Also in this repo
- 14 client 1 n8n workflows (inactive, no credentials, placeholder IDs).
- `client1-state` helper (memory, guardrails, approvals, batches, Viral coach) with offline tests.
- `browser-agent` service, guardrails templates, `bin/` service scripts and a watchdog.
